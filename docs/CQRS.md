# CQRS-命令查询责任分离

> 命令查询责任分离（CQRS）是一种设计模式，可将数据存储的读取和写入操作隔离到单独的数据模型中。 此方法允许每个模型独立优化，
并可以提高应用程序的性能、可伸缩性和安全性。

## 核心概念

命令（Command）：指会改变系统状态的操作（写操作）

查询（Query）：指不会改变系统状态的读取操作

责任分离：将处理命令和查询的逻辑和数据模型分离开来。 

## 实践

`Query`: 只负责查询

`Command`: 只负责写操作（创建、更新、etc.)，原教旨主义的 Command 只应返回 error,
创建后需要用于在代码中流转的数据通过 Event-Sourcing 实现。
但是我们可以在**代码层面为写操作返回值来简化设计**
